# Play Console

- Package: `ng.hausanovels.app`
- Target Android: API 36
- Version code: 210
- Version name: 2.1.0

When Play App Signing is enabled, copy the SHA-256 fingerprint under the App signing key certificate into the WordPress PWA settings. The Play-distributed APK is signed by Google, so the upload-key fingerprint alone will not verify App Links for store installs.
