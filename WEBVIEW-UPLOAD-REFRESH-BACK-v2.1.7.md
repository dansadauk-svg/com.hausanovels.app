# HausaNovels Android WebView v2.1.7

This release keeps the working HausaNovels WebView app and adds only the requested app-side controls.

## Added

- Publisher cover upload/file chooser support inside the Android WebView.
- Pull down to refresh the current page.
- Left-edge swipe-right gesture to go back inside the app navigation history.
- Android back button behavior is preserved.

## Preserved

- Package name: `ng.hausanovels.app`
- Signing secret names: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`
- Google Sign-In external browser flow and app return handling
- Existing splash design and WebView app shell
